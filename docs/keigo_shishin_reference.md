### 本リポジトリの方針

利用規約上は全文の再配布も認められうるが、本リポジトリでは以下の方針を採る。

1. **答申本文の全文またはそれに準ずる分量は同梱・再配布しない。** PDF も含めない。
   規範判定に必要なのは分類・語形・条件であって本文そのものではないため。
2. 判定の根拠として必要な**短い引用（定義文・語例・要点の一文）のみ**を
   `deference/norms.py` の `CITATIONS` に保持する。
3. すべての引用に **章・節・問い番号・ページ**を付し、原典 URL を併記する。
   利用者が原典で確認できる状態を保つ。
4. 出典表記は README・データセットカード・CLI 出力・Gradio UI のすべてに置く。

出典表記の文言:

```
出典: 文化審議会答申「敬語の指針」（文化庁）を加工して作成
https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/keigo_tosin.pdf
文化庁ウェブサイトのコンテンツは「文部科学省ウェブサイト利用規約」に従う。
同規約は「公共データ利用規約（第1.0版）」に準拠し、CC BY と互換性があるとされ、
出典を記載すれば複製・公衆送信・翻案等を自由に行える。
```

生成コーパスは答申の分類・語形・条件を規則として実装した上で機械的に構成したもので
あり、答申本文の文章ではない。したがって「加工して作成」に該当する。

### 指針の射程外について

以下は「敬語の指針」が扱っていない。これらを扱う際は **指針を根拠に見せかけない**
こと（`Citation.source` を分ける）。

| 事項 | 扱い |
|---|---|
| さ入れ言葉（「休まさせていただく」） | 指針に記述なし。五段動詞の活用規則を根拠とする。参考として文化庁「国語に関する世論調査」に言及 |
| ら抜き言葉 | 指針に記述なし |
| 「了解しました／承知しました」の使い分け | 指針に記述なし。揺れとして扱う |
| 敬体と常体の混在 | 指針は分類として言及するのみで可否は論じていない。文章作法上の観点として提示し、規範違反とは呼ばない |

## 分類（第2章 第1「敬語の種類と働き」）

指針は敬語を **5種類**に分ける（従来の3分類のうち「謙譲語」を2つに分けたもの）。

| 分類 | 型 | 定義（要点、p.14–21） |
|---|---|---|
| 尊敬語 | 「いらっしゃる・おっしゃる」型 | 相手側又は第三者の行為・ものごと・状態などについて、その人物を立てて述べるもの |
| 謙譲語Ⅰ | 「伺う・申し上げる」型 | 自分側から相手側又は第三者に向かう行為・ものごとなどについて、その向かう先の人物を立てて述べるもの |
| 謙譲語Ⅱ（丁重語） | 「参る・申す」型 | 自分側の行為・ものごとなどを、話や文章の相手に対して丁重に述べるもの |
| 丁寧語 | 「です・ます」型 | 話や文章の相手に対して丁寧に述べるもの |
| 美化語 | 「お酒・お料理」型 | ものごとを、美化して述べるもの |

**この表が Deference の設計の出発点である。** 尊敬語は〈行為者〉を立て、謙譲語Ⅰは
〈向かう先〉を立てる。つまり適否の判定には、述語の表層ではなく
**「誰の行為で、誰に向かうのか」** が要る。表層パターンだけを見る規則ベースの
校正ツールがこの類の誤りを捕まえられないのは、この情報を持たないからである。

### 向きの原則（第2章 第1-6【解説1】, p.22）

> 「自分側は立てない」というのが、尊敬語や謙譲語Ⅰを使う場合の基本的な原則である。

- ×「父は来週海外へいらっしゃいます」— 尊敬語で自分側を立てている
- ×「明日父のところに伺います」— 謙譲語Ⅰが〈向かう先〉の父を立てている
- ○「父は来週海外へ参ります」「明日父のところに参ります」— 謙譲語Ⅱなら問題ない

### 第三者の扱い（第2章 第1-6（3）イ, p.22–23）

> 自分から見れば、立てるのがふさわしいように見えても、「相手から見れば、立てる
> 対象とは認識されないだろう」と思われる第三者については、立てない配慮が必要である。

なお同ページの注は、課員が課長のことを部長に述べる場合について **二通りの考え方が
どちらも成り立つ**とし、「こうした点も含めて、（3）イをどこまで適用するかについては、
個人差もあるようである」と述べている。→ **揺れとして扱う根拠。**

## 敬語の形（第2章 第2, p.24–29）

### 尊敬語

- 特定形: いらっしゃる（行く・来る・いる）／おっしゃる（言う）／なさる（する）／
  召し上がる（食べる・飲む）／下さる（くれる）／見える（来る）
- 変則的な「お(ご)……になる」: ご覧になる（見る）／おいでになる／お休みになる（寝る）／
  お召しになる（着る）
- 一般形: お(ご)……になる／……(ら)れる／……なさる／ご……なさる／お(ご)……だ／
  お(ご)……くださる
- 「お」「御」の使い分け: 和語は「お＋連用形」（読む→お読みになる）、
  漢語サ変は「ご＋語基」（利用する→ご利用になる）
- 作れない場合あり: ×お死にになる ×ご失敗になる ×ご運転になる
- 可能形は **まず尊敬語にしてから可能形**（召し上がれる／お読みになれる／ご利用になれる）
- 注記: 「お(ご)……する」は謙譲語Ⅰの形であり、尊敬語として使うのは適切ではない
- 注記: 「ご……される」は、本来、尊敬語の適切な形ではないとされている

### 謙譲語Ⅰ

- 特定形: 伺う（訪ねる・尋ねる・聞く）／申し上げる（言う）／存じ上げる（知る）／
  差し上げる（上げる）／頂く（もらう）／お目に掛かる（会う）／お目に掛ける・
  ご覧に入れる（見せる）／拝見する（見る）／拝借する（借りる）
- 一般形: お(ご)……する／お(ご)……申し上げる／……ていただく／お(ご)……いただく
- **作れるための条件（【補足イ－1】, p.27）**:
  > これらの語は＜向かう先＞を立てる謙譲語Ⅰなので、＜向かう先＞の人物がある動詞に
  > 限って、これらの形を作ることができる。

  ×お食べする ×ご乗車する（〈向かう先〉が想定できない）
  ×お憧れする ×ご賛成する（慣習上作れない）

### 謙譲語Ⅱ（丁重語）

- 特定形: 参る（行く・来る）／申す（言う）／いたす（する）／おる（いる）／
  存じる（知る・思う）
- 一般形: ……いたす（サ変動詞のみ）
- 謙譲語Ⅰ兼Ⅱの一般形: お(ご)……いたす
- 名詞: 愚見・小社・拙著・弊社（ほぼ書き言葉専用）

### 丁寧語・美化語

- 丁寧語: 「です」「ます」。形容詞＋です（「高いです」）は
  **既にかなりの人が許容するようになってきている**（p.28）
- 美化語: 「お酒」「お料理」。一部「ご祝儀」のように「ご」によるものもある

## 二重敬語と敬語連結（第2章 第2-6, p.30–31）

### 二重敬語の定義

> 一つの語について、同じ種類の敬語を二重に使ったものを「二重敬語」という。
> …「二重敬語」は、一般に適切ではないとされている。ただし、語によっては、
> **習慣として定着しているものもある。**

**習慣として定着している二重敬語の例**（＝ Deference が誤りにしないもの）:

- 尊敬語: お召し上がりになる、お見えになる
- 謙譲語Ⅰ: お伺いする、お伺いいたす、お伺い申し上げる

### 敬語連結

二つ以上の語をそれぞれ敬語にして「て」でつないだものは二重敬語ではない。

> 「敬語連結」は、多少の冗長感が生じる場合もあるが、個々の敬語の使い方が適切で
> あり、かつ敬語同士の結び付きに意味的な不合理がない限りは、**基本的に許容される**
> ものである。

- 許容: お読みになっていらっしゃる／お読みになってくださる／
  お読みになっていただく／ご案内してさしあげる
- 不適切: 伺ってくださる／伺っていただく／伺ってください
  （「伺う」が自分側を立ててしまうため）

## 過剰指摘を避ける根拠（第1章）

- 第1章 第1-3「『自己表現』としての敬語使用」（p.7）
- 第1章 第2-2「世代や性による敬語意識の多様性」（p.8）
  > 男女の違いや世代の違いなどによって画一的に考える態度は避けるべきである。

  同節は「植木に水をあげる」について、旧来の規範からは誤用とされるが
  「意味的な変化は既に進行し、定着しつつある」と述べる。
- 第3章 第1-4「敬語は過剰でなく適度に使う」（p.35）

**これらが、Deference が「揺れ」を誤りにしない設計上の根拠であり、
UI 文言を断定的にしない根拠でもある。**
